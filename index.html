Casework Sanitisation Tool

Getting started

  1. Click Open casework folder and grant access to a folder that will hold your Casework, Casework_sanitised, Casework_closed, and Casework_sanitised_closed subfolders. The tool will create any that are missing.
  2. Add a case with New case, or open an existing case from the sidebar.
  3. Open a document to sanitise it. Use Copy sanitised to send tokenised text to an AI service. Use Paste rehydrate to convert the reply back to real identifiers.

This tool runs entirely in your browser. No case data is sent anywhere.

This browser does not expose the File System Access API. Please use Chrome, Edge, or Opera.

Getting started

Pseudonymise casework before it leaves this machine.

This tool sits between the case file and the AI service. It runs entirely in the browser tab — no case data is transmitted anywhere.

  1. Click Open casework folder and grant access to a folder that will hold your Casework, Casework_sanitised, Casework_closed, and Casework_sanitised_closed subfolders. Missing ones are created.
  2. Add a case with New case, or open an existing case from the sidebar.
  3. Open a document to sanitise it. Use Copy sanitised to send tokenised text to an AI service. Use Paste rehydrate to convert the reply back to real identifiers.
Requires Chrome, Edge or Opera (File System Access API). No server, no build step, no dependencies to install.

This browser does not expose the File System Access API. Please use Chrome, Edge, or Opera.
